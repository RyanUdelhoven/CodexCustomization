# Custom skills maintenance

After creating or changing any custom skill, or completing a deconfliction pass, commit the finalized task changes and push to `origin` (`git@github.com:Arkmer/codex_skills.git`). This is standing user authorization; required execution approvals still apply. One push after a coordinated task is sufficient.

Apply `skill-deconfliction/SKILL.md` before finalizing skill creation or changes. Its synchronization section defines commit scope, unchanged reviews, and failure handling. Preserve unrelated working-tree and staged changes. Do not force-push or rewrite history. Report any synchronization blocker.
