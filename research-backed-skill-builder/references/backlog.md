# Code and context skill backlog

Use this list to identify and distinguish the skills proposed for this user. Research each requested target independently; the notes below are candidate outcomes, not established methods.

| Target | Intended outcome |
|---|---|
| Context audit | Find avoidable context and session token costs. Check the existing personal `context-audit` skill first. |
| Repository navigator | Locate relevant entry points, symbols, callers, and tests for a specific task. |
| Tool-output summarizer | Preserve full logs separately and surface actionable failures with pointers. |
| Handoff writer | Record decisions, changed files, verification, and remaining work for a future session. |
| Performance optimizer | Measure a baseline, profile a real workload, and verify improvements against it. |
| Focused refactor | Simplify a bounded code area while preserving agreed behavior. |
| Architecture mapper | Build or update durable documentation of module boundaries and important flows. |
| Decision recorder | Capture consequential choices, rationale, constraints, and alternatives. |
| Code-change verification | Adapt the published Agents SDK workflow to the target project's checks. |
| Test coverage improver | Identify meaningful coverage gaps and prioritize tests. |
| Docs sync | Compare documentation with source and fix or report drift. |

For agent navigation, keep the distinction clear: the navigator answers a task-specific question; the mapper maintains the repository's ICM; docs sync checks whether that context remains accurate.
