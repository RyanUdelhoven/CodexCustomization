# Handoff Writer

Use the requested destination or an existing handoff convention; otherwise return a copyable handoff in chat. Check relevant working-tree state and verification evidence when available. Record the objective, acceptance criteria, key constraints and decisions, current branch or workspace if relevant, completed work with pointers, remaining work, and the first concrete next action. Separate completed, unverified, and blocked work; include the command or evidence needed to resume. Omit raw transcripts, credentials, and obsolete attempts unless they explain a live constraint. Writing the handoff does not send it, create a chat, or transfer ownership.

For a branch handoff, include the originating chat identity, participation record location, and any tracking gaps from feature-branch's [participation protocol](../feature-branch/references/chat-participation.md). Tell the receiving chat to register itself before managing the branch. Preserve earlier participants; a handoff never resets provenance or authorizes publication or archival. Chat archival requires a separate explicit user request.
