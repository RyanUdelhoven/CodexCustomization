# Effectiveness evaluation

Compare matched tasks with and without the suite, or before and after a change. Use fresh sessions, the same repository state, model, settings, tools, and acceptance criteria. Repeat runs where practical.

Include a routine known-file edit, an unfamiliar behavior trace, and a change that uses several workflows. Record success, selected skills, repeated reads or commands, total tokens, elapsed time, and human corrections. Check whether unrelated skills activate and whether required gates still run. Include audit and maintenance costs when assessing net savings.

Report measured results separately from static walkthroughs. Do not run costly evaluations outside the authorized scope.
